# API Design

None — this is a fully static site with no backend or third-party API
calls.

-   Contact uses direct `mailto:`/`tel:` links, not a form service
-   Project "Live" links point straight to external listings (the
    Salesforce package install URL, the Play Store listing) — the site
    doesn't call any API on their behalf

If a contact form or CMS is added later (see
[future-roadmap.md](future-roadmap.md)), document its request/response
shape here.
