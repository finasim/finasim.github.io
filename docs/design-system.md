# Design System

## Colors

-   Primary `#2563EB`
-   Secondary `#7C3AED`
-   Accent `#06B6D4`
-   Dark background `#050816` / surface `#111827` / card `#0b1220`
-   Light surface `#f8fafc`

Defined in `tailwind.config.js`, toggled via the `dark` class strategy.

## Typography

-   Headings: Space Grotesk
-   Body: Inter

Both self-hosted via `@fontsource` (no external font CDN request).
