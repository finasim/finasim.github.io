# Tech Stack

React 19, TypeScript 6, Vite 8, Tailwind CSS v3 (via PostCSS), Framer
Motion, React Router v7, React Helmet Async.

Icons: lucide-react (general UI) and react-icons (GitHub/LinkedIn brand
icons). clsx for conditional classNames. Fonts (Inter, Space Grotesk)
are self-hosted via `@fontsource`, not loaded from Google Fonts CDN.

No backend, database, or third-party API integration.
